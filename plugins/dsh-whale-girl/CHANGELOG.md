### 性能 / 交互

### 已知问题
- **DSH 流式输出时挂件卡顿**：agent 输出长文字（流式）时，挂件（及同页 UI）在相邻 token 之间会卡顿，输出完毕立即恢复流畅。
  **问题真正所在不在本插件**：DSH 前端（官方 `deepseek-ai/deepseek-harness`，DSH Desktop 通过 submodule 引入）在流式输出时**每收到一个 token 就整体重建当前 assistant 消息**（`assistant.ts` 的 `updateChunk` 每 chunk 复制 blocks 并重渲染整条消息），占用主线程；本挂件与它同页面/同主线程，被连带卡住。虚拟列表已解决长会话整体渲染，但**“流式每 token 全量重建当前消息”是剩余瓶颈**。
  本插件已做缓解（`thinking` 暂停信息面板物理 + transform 定位等），**根治在 DSH 的流式渲染层**（该问题已反馈给 DSH Desktop 作者，见其 issue #747）。
