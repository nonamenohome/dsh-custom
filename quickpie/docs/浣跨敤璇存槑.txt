QuickPie 轮盘夹 · 使用说明
================================

一、怎么开始
------------
1. 把整个 QuickPie 文件夹解压到一个你固定放软件的位置（比如 D:\Tools\QuickPie）
   ⚠️ 不要放在压缩包里直接双击，也不要放在系统盘临时目录
2. 双击「便携模式启动.cmd」
   - 数据存在程序目录的 PortableData 里，删掉文件夹就彻底卸载
   - 也可以直接双击 QuickPie.exe（数据会存到 %APPDATA%\QuickPie）
3. 第一次启动会弹一次轮盘，并生成几个示例条目（桌面、下载、GitHub、计算器）

如果双击时 Windows 提示「已保护你的电脑」：
   点「更多信息」→「仍要运行」。这是未签名程序的常规提示，不是病毒。


二、基本用法
------------
- 呼出轮盘： Ctrl + Shift + Space（任意窗口都能用）
- 关闭轮盘： Esc
- 打开条目： 鼠标点扇区，或按 Enter
- 扇区切换： 方向键；超过 12 项时滚轮翻页

轮盘中心显示当前条目的名字和完整路径；路径失效的条目会灰掉并带红点。


三、添加自己的东西
------------------
方式一：拖拽
   从资源管理器把文件夹 / 程序 / 快捷方式 / 文件拖到轮盘的某个扇区上，松手即加入。

方式二：粘贴（最快）
   复制网址或路径 → 呼出轮盘 → Ctrl + V → 回车
   · 复制的是「人名 / 群名」这类裸名字时，会自动按「微信会话」添加
   · 也可以按 Tab（或点左边那个小胶囊）在「条目 / 微信会话」之间切换

方式三：管理器
   托盘图标右键 → 管理条目，或轮盘上按 Tab
   管理器里可以搜索、筛选、拖动排序、改名、换图标、改路径、删除


四、二级分组
------------
1. 管理器 → ＋添加 → 类型选「分组」→ 填名字 → 保存
2. 把别的条目拖到这个分组行的中间，它就变成二级条目
3. 轮盘上悬停该分组扇区，外侧展开小扇区，点哪个开哪个

点一级扇区 = 打开分组的「默认目标」，比如「文件夹」组默认打开 C:\
如果默认目标是个已经在运行的程序，会直接唤出它的窗口，不会重复启动。


五、微信 / 钉钉会话
------------------
创建一个「会话」条目，会话名填微信里显示的名字（单聊、群都行）：
   · 点击后：微信会到前台，搜索框自动填好这个名字，你按一下回车即进入
   · 如果该会话有独立聊天窗口，会直接切过去，不用回车

快速添加：复制会话名 → 呼出轮盘 → Ctrl+V → 回车（会自动识别为会话）


六、常见问题
------------
Q: 托盘里找不到图标？
A: 某些系统/远程桌面会话里托盘图标会创建失败。不影响使用：
   Ctrl+Shift+Space 照常呼出，启动时也会自动弹一次轮盘。

Q: 图标变成字母牌？
A: 部分商店应用（UWP）取不到图标。管理器里选中它 →「自定义图标」→ 选一张 png/ico。

Q: 点条目没反应或报「打开失败」？
A: 看程序目录下 PortableData\open.log，最后一行会写明失败原因。

Q: 想删干净？
A: 便携模式：删掉整个文件夹。常规模式：删掉文件夹 + %APPDATA%\QuickPie。


七、说明
--------
- 纯本地程序，不上传任何数据（网址图标会向对应网站请求 favicon）
- 数据就是一个 data.json，可自行备份或换机器
- 版本 0.9.4 · Windows 10 / 11
