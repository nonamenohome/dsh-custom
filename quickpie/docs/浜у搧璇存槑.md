# QuickPie 轮盘夹 · 产品说明

> 版本 0.7.5 · Windows 10/11 · Electron 桌面应用

---

## 一、它是什么

QuickPie 是一个**常驻系统的轮盘式快捷启动器**。把每天要点十几次的文件夹、网址、程序收进一个轮盘，按下 `Ctrl+Shift+Space`，轮盘在鼠标位置展开，点一下就打开。

它解决的具体问题是：桌面图标越堆越乱、任务栏放不下、开始菜单要翻好几层、浏览器书签要开新标签才能点。这些入口本质上是同一类东西——**高频、固定、路径已知**，值得一个一键到达的入口。


---

## 二、核心能力

### 1. 轮盘

- 光标处展开：`Ctrl+Shift+Space`（可改），`Esc` 关闭
- 一屏 12 个扇区，超出用滚轮翻页
- 悬停即预览：中心圆显示名称与完整路径，路径失效的条目自动灰掉并标红点
- 点击扇区或按 `Enter` 打开；方向键可在扇区间移动

### 2. 二级分组

一级是「分组」，二级是这个分组下的具体条目。悬停分组扇区时，**外侧展开小扇面**，每个小扇面是一项：

```
        文件夹  ← 一级（默认目标 C:\）
      ┌──┬──┬──┐
      │下│工│常│  ← 二级小扇面（具体路径）
      │载│区│用│
```

典型用法：

| 一级 | 默认目标 | 二级 |
|---|---|---|
| 文件夹 | `C:\`（我的电脑） | 下载、工作区、素材库…… |
| 网址 | Edge 初始页 | GitHub、B 站、文档站…… |
| 某个项目 | 项目根目录 | 源码、构建产物、部署脚本 |

点一级扇区 = 打开默认目标；点二级小扇面 = 打开那一项。二级为空时，点了会提示「没有设置默认目标」。

### 3. 外环窗口列表

悬停「应用」类条目时，它的每个窗口会在外侧展开成胶囊（例如微信的「微信」「聊天」「图片和视频」），点胶囊直接把那个窗口切到前台。窗口枚举由常驻 PowerShell 完成，不额外落地可执行文件。

### 4. 快速添加

| 方式 | 操作 |
|---|---|
| 拖拽 | 从资源管理器拖文件/文件夹/`.lnk` 到某个扇区，落点决定插入位置（拖到分组上则成为它的二级） |
| 粘贴 | 呼出轮盘 → `Ctrl+V`，输入条预填剪贴板内容，回车确认；悬停分组时直接加进该分组 |
| 就地输入 | 呼出轮盘 → 直接敲字，输入条出现，回车添加 |
| 管理器 | `＋ 添加` / `Ctrl+N`，可选类型、浏览路径、填启动参数 |
| 剪贴板 | 管理器底部「从剪贴板添加」 |

`.lnk` 会被解析出真实 exe 与启动参数；`.url` 会自动转成网址条目。

### 5. 管理器

列表 + 编辑器的双栏界面：

- 搜索（名称、路径、域名）、按类型筛选
- 拖动行排序；**拖到分组行中间**即成为它的二级条目
- 二级条目可就地改名、改目标路径，或用「浏览」重选；「移出」还原为一级
- 分组内「＋ 新增二级条目」直接添加
- 换图标 / 自定义图标（任意 png、ico、jpg）
- 删除、导入导出数据、打开数据目录

### 6. 外观与系统集成

- 浅色 / 深色 / 跟随系统三套主题，中性灰配色（取自 PiPie 的视觉语言）
- 空闲时中心显示应用图标，悬停后让位给条目信息
- 托盘图标：左键呼出轮盘，右键菜单（打开轮盘 / 管理 / 开机自启 / 退出）
- 开机自启（写入注册表 Run 项）
- 启动即弹一次轮盘，双击后立刻有反馈

## 三、数据与隐私

- 数据全部本地：`data.json`，无网络账号、无云端同步
- 便携模式：程序目录下的 `PortableData`（快捷方式通过 `--user-data-dir` 指定）
- 每次打开动作记录到 `open.log`（成功/失败与所用方式），便于排查
- 数据结构：

```json
{
  "version": 1,
  "settings": { "hotkey": "...", "theme": "auto", "autoLaunch": false },
  "items": [
    {
      "id": "...", "type": "group|folder|url|app|file",
      "name": "文件夹", "target": "C:\\",
      "args": "", "icon": "data:image/png;base64,...",
      "children": [ { "id": "...", "type": "folder", "name": "下载", "target": "..." } ]
    }
  ]
}
```

支持导入/导出整份 JSON，便于迁移与备份。

## 四、技术实现要点

| 模块 | 做法 |
|---|---|
| 界面 | Electron（BrowserWindow 透明置顶窗口 + 内嵌 HTML/CSS/SVG） |
| 轮盘绘制 | SVG 环形扇区（`path` 的 `A` 圆弧），二级小扇面同样用环形扇区路径 |
| 动画与主题 | CSS 变量 + `cubic-bezier`，明暗两套 token |
| 图标 | `app.getFileIcon` → 目标 exe → 原始路径 → PowerShell `ExtractAssociatedIcon` 四级回退；UWP 应用从 Appx 包清单取 PNG；网址抓 favicon |
| 窗口枚举 | 常驻 PowerShell（`Add-Type` 内存编译 C#）`EnumWindows` → PID → exe，800ms 轮询 |
| 打开动作 | 文件夹/应用/文件走 `shell.openPath`；网址走 `shell.openExternal`；每次结果写入日志 |
| 配置 | 主进程持有状态，通过 IPC 与渲染层同步，变更即落盘 |

## 五、已知边界

1. **没有实时窗口预览**：PiPie 用 `DwmRegisterThumbnail` 把其他窗口画面合成进轮盘，Electron 拿不到这个能力，外环只显示窗口标题
2. **没有鼠标侧键呼出**：需要全局鼠标钩子，Electron 原生 API 做不到（且开发者本人的鼠标没有侧键）
3. **二级一次最多 8 个**：小扇面按子项数量等分，过多会窄到只剩图标
4. **不支持三级**嵌套
5. **部分商店应用（UWP）图标**无法自动获取：其图标在 `WindowsApps` 包里且本机 `Get-AppxPackageManifest` 失效，需在管理器里「自定义图标」
6. **托盘图标依赖系统会话**：某些受限会话（远程桌面、沙箱）无法创建托盘图标，程序会自动降级为「启动即弹轮盘 + 热键」

## 七、一分钟上手

1. 双击桌面「QuickPie 轮盘夹」，轮盘会立刻弹出一次
2. `Esc` 关闭；任何时候按 `Ctrl+Shift+Space` 再唤出
3. 拖一个文件夹到某个扇区上松手，它就进来了
4. 想看分组：悬停「文件夹」扇区，外侧三个小扇面就是二级
5. 要改名字或路径：按 `Tab` 或托盘菜单打开管理器
